# Kỷ Yếu 25 Năm Agribank (1999 — 2024)
## "Tự Hào Truyền Thống, Kiến Tạo Tương Lai"

Trang kỷ yếu điện tử dạng **Scrollytelling** kỷ niệm 25 năm thành lập Trường Đào tạo cán bộ, công bố chuyển đổi thành **Viện Nghiên cứu và Đào tạo Agribank**.

### 🌟 Tính năng nổi bật
- **Hiệu ứng Scrollytelling:** Cuộn trang điện ảnh mượt mà bằng GSAP & ScrollTrigger.
- **Hệ thống nền chủ đề:** Mỗi phần một hình nền nghệ thuật riêng biệt, màu sắc lắng đọng, trang trọng.
- **Tương tác đọc bài viết:** Xem chi tiết các bài viết ([Thúy], [SEI Award], [Thắp sáng bản làng], [PA], [Ngọc], [Diệp - Phương], [Thơ C. Thanh Hương], [Sếp Lưu]).
- **Âm thanh nền khánh tiết:** Tự động tạo giai điệu hòa âm trầm ấm bằng Web Audio API mà không cần file ngoài.
- **Tương thích:** Tối ưu hóa 100% hiển thị trên điện thoại, máy tính bảng và màn hình lớn.
